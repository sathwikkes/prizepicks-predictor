# Sample fixtures

**`synthetic_game_logs.csv` is synthetic data.** Player names are fictional and every
stat line is randomly generated by `scripts/generate_synthetic_fixture.py` with a fixed
seed. It is not real NBA data and must never be used to draw conclusions about real
players. It exists only to exercise the ingestion, storage, and query layers.

Regenerate with:

```bash
uv run python scripts/generate_synthetic_fixture.py
```
